# Blue-Chip Dip Finder (demo)

A single-page demo that lists S&P 500 blue-chip shares that have fallen over the last 3 months, with a 10–80% fall slider, full and high-level views, and a rule-based Yes/No buy check per share.

Data snapshot: close of 13 Nov 2026 (StatMuse, StockAnalysis.com). Demo only, not financial advice.
